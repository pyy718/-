# 域名连通率检测（yuyan版 / Vercel）

功能：上传 `txt` → 批量检测 → 下载输出 `txt`（保持原格式，并替换/补充每行的 `连通率XX%`）。

默认参数（可在页面改）：
- 探测次数：2
- 并发：8
- 超时：8000ms
- 成功判定：`mode=1`（2xx/3xx 视为成功；更接近“能正常打开”的感觉）

## 部署到 Vercel

方式 1：GitHub 导入（推荐）
1. 把本目录推到一个 GitHub 仓库
2. Vercel 新建项目 → Import Git Repository → Deploy

方式 2：Vercel CLI
1. 安装：`npm i -g vercel`
2. 在本目录执行：`vercel`（按提示登录/创建项目）
3. 上线：`vercel --prod`

## 说明
- 这是“从 Vercel 机房视角”去请求网址的可达性检测，不是 itdog 多节点。
- 结果可能受目标站对机房 IP 限制/风控影响。

## 本地引擎（完全按本地版口径）

如果你要和本地版（Playwright 打开 itdog / 142 节点 / 读取“访问失败 N”）一致：
1. 下载并解压：`packages/域名连通检测工具_本地引擎_20260206.zip`
2. 双击启动：`运行_启动本地引擎(给网页用).bat`
3. 打开网页，勾选“本地引擎”，再上传 txt 开始检测
